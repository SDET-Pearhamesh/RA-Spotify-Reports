# 🎵 Spotify Playlist API Test Reports

</div>

This repository hosts **automated test reports** for the Spotify REST API testing suite. Every day at 10 AM, our Jenkins CI/CD pipeline runs comprehensive REST API tests and publishes beautiful, interactive **Allure reports** right here on GitHub Pages.

## 📊 **Quick Access**

| 🎯 **Report Type** | 🔗 **Direct Link** | 📝 **Description** |
|-------------------|-------------------|-------------------|
| **🏠 Main Dashboard** | [🏠 Browse All Reports](https://sdet-pearhamesh.github.io/RA-Spotify-Reports/) | Landing page with all available reports |
| **📊 Latest Report** | [📊 View Latest](https://sdet-pearhamesh.github.io/RA-Spotify-Reports/latest/) | Most recent test execution results |
| **📁 Build Archive** | [📁 Browse Archive](https://sdet-pearhamesh.github.io/RA-Spotify-Reports/) | Access any specific build report |
| **💻 Source Code** | [💻 Test Suite](https://github.com/SDET-Pearhamesh/RestAssured_Practise) | REST Assured automation framework |

## 🎨 **Features**

### 🤖 **Automated Pipeline**
- ⏰ **Daily Execution** - Runs automatically every day at 10:00 AM IST
- 📧 **Email Notifications** - Instant alerts with report links and build status
- 🔄 **Auto-Deployment** - Reports published to GitHub Pages automatically
- 📦 **Archive Management** - Keeps last 30 build reports for historical analysis
- ⚡ **Fast Access** - Direct links to latest and archived reports

### 🎵 **Spotify API Coverage**
- 🎤 **Playlist Management** - Create, update, get, delete playlist operations
- 🔍 **Search Operations** - Search tracks, albums, artists functionality
- ❌ **Negative Scenarios** - Error handling and validation testing
- 🔐 **Authentication Testing** - OAuth token validation and security tests
- 📊 **Performance Metrics** - Response time and load testing

### 📈 **Report Features**
- 🎨 **Interactive Allure Reports** - Rich visualizations and detailed test results
- 📊 **Trend Analysis** - Historical test execution trends
- 🏷️ **Test Categories** - Organized by features and test types
- 📝 **Detailed Logs** - Step-by-step execution details
- 📷 **Screenshots** - Visual evidence of test execution
- 💾 **Export Options** - Download reports in multiple formats
