## 🎵 Spotify Playlist API Test Reports

</div>

This repository hosts **automated test reports** for the Spotify REST API testing suite. Every day at 10 AM, our Jenkins CI/CD pipeline runs comprehensive REST API tests and publishes beautiful, interactive **Allure reports** right here on GitHub Pages.

## 📊 **Quick Access**

| 🎯 **Report Type** | 🔗 **Direct Link** | 📝 **Description** |
|-------------------|-------------------|-------------------|
| **📊 Latest Report** | [📊 View Latest](https://sdet-pearhamesh.github.io/RA-Spotify-Reports/latest/) | Most recent test execution results |
| **💻 Source Code** | [💻 Test Suite](https://github.com/SDET-Pearhamesh/RestAssured_Practise) | REST Assured automation framework |

## 🎨 **Features**

### 🤖 **Automated Pipeline**
- ⏰ **Daily Execution** - Runs automatically every day at 10:00 AM IST
- 📧 **Email Notifications** - Instant alerts with report links and build status
- 🔄 **Auto-Deployment** - Reports published to GitHub Pages automatically
- 📦 **Archive Management** - Keeps last 30 build reports for historical analysis
- ⚡ **Fast Access** - Direct links to latest and archived reports

## 📁 **Repository Structure**

```
RA-Spotify-Reports/
├── 📊 latest/                  # Latest test report
│   ├── index.html              # Report dashboard
│   ├── data/                   # Test execution data
│   └── export/                 # Exportable formats
├── 📁 archive/                 # Historical reports
│   ├── build-8/                # Build #8 report
│   ├── build-12/               # Build #12 report
│   └── ...                     # More builds (last 30 kept)

```

## 🔗 **URL Patterns**

Access any specific build report using these patterns:


## 📧 **Email Notifications**

Stakeholders receive automated email reports containing:
- ✅ **Build Status** - Success/Failure with visual indicators
- 🔗 **Direct Links** - Quick access to latest and specific build reports
- 📈 **Test Metrics** - Pass/fail counts and execution summary
- 📎 **Jenkins Logs** - Complete build logs attached
- 🕐 **Execution Details** - Timestamp, duration, and build information
- 🎯 **Quick Actions** - One-click access to reports and Jenkins

## 🛠️ **Technical Stack**

- **🧪 Testing Framework**: REST Assured + TestNG
- **📊 Reporting**: Allure Framework
- **🤖 CI/CD**: Jenkins Pipeline
- **🌐 Hosting**: GitHub Pages
- **📱 Notifications**: Jenkins Email Extension
- **🔧 Build Tool**: Maven
- **☕ Language**: Java 11
